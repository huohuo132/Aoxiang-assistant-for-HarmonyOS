# Aoxiang-assistant-for-HarmonyOS
# 翱翔助手for HarmonyOS
## 使用说明：
### 目前没有上线app store，想要使用的朋友可以直接下载hap安装包自行无线调试安装，建议使用小白调试助手
#### 0. 多次点击版本号，打开开发人员模式，在系统-开发人员选项中打开“无线调试”。
#### 1. 下载hap安装包，解压后在小白调试助手中选择“无线调试”，点击“添加设备”，输入设备ip地址，点击“连接”，连接成功后点击“安装应用”，选择解压后的hap安装包进行安装。
#### 2. 安装完成后，点击“启动应用”，即可在设备上使用翱翔助手。
ps: 目前只适配了手机，平板和电脑等设备以后再说（会搞的）
